ROCK PAPER SCISSORS GAME  is a console-based Rock Paper Scissors game in which the player competes against a computer opponent. It was developed using JavaScript as part of The Odin Project JavaScript curriculum to facilitate practice in programming logic, functions, loops, conditionals, and problem-solving. This project is my first JavaScript application built from scratch. It challenged me to think through a problem, break it into smaller tasks, and implement a working solution using JavaScript.

The game plays five rounds against a computer opponent that makes a random choice each round using Math.random(). It accepts player input through the browser prompt and keeps track of both the human and computer scores throughout the game. To improve the user experience, the game accepts uppercase and lowercase input, and it validates the player's choice by repeatedly asking for a valid option whenever an invalid value is entered. After all rounds have been completed, the final scores are displayed and the overall winner is announced.

Building this project helped me gain a much better understanding of JavaScript fundamentals. I learned how to create and organize functions, pass arguments between functions, return values that other parts of the program can use, and use conditional statements to control the game's logic. I also became more comfortable using loops, managing variables and scope, collecting user input with prompt(), and debugging errors. One of the biggest lessons from this project was realizing the importance of planning a solution before writing code and thinking about edge cases, such as handling invalid user input.

This is the console version of the game. In the future, I plan to build a graphical user interface using DOM manipulation, replace browser prompts with interactive buttons, display the scores directly on the webpage, and add styling and animations to create a better user experience.

This project was completed as part of The Odin Project Foundations JavaScript curriculum.
